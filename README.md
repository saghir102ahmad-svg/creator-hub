# Creator Hub — Personal Portfolio Website

A full-stack personal portfolio, video library, gaming channel, courses & digital store — built with **Python + SQLite + vanilla HTML/CSS/JS**.

## Features
- 🎮 Gaming & YouTube video library (filterable by category)
- 📚 Courses & digital product bundles store  
- 📧 Business inquiry form (saved to database)
- 💌 Newsletter subscriber list
- ⚙️ Admin Control Center (edit profile, avatar, publish videos)
- 🌙 Multiple themes (Cyberpunk Dark, Neon Glass, Midnight Blue)

## Local Development

```bash
python run.py
# App runs at http://localhost:8000
```

## Deploy to Railway (Free)

1. Push this folder to a GitHub repo
2. Go to [railway.app](https://railway.app) → New Project → Deploy from GitHub
3. Select this repo — Railway auto-deploys!
4. Add your custom domain in Railway Settings → Domains

## Tech Stack

- **Backend**: Python 3 (stdlib only — no pip packages needed)
- **Database**: SQLite3 (file-based, zero config)
- **Frontend**: HTML5 + CSS3 (Glassmorphism) + Vanilla JS
- **API**: REST API served at `/api/*` endpoints
